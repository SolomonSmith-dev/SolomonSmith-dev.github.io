# 90-second hiring-manager skim path (draft)

**Status:** draft pending DI-01 + DI-17  
**Target:** cold visitor decides "worth an interview" in <=90s

## Path

1. **0-10s — Home hero**  
   Name, AI/Backend Engineer, thesis line, availability Jan 2027, primary CTA (email/resume per DI-01).

2. **10-25s — Metrics strip**  
   CourtRules 1,653 judges · ARDA 577 tests · PhishGuard AUC 0.9943.

3. **25-50s — Selected work #1**  
   CourtRules card: fail-closed citation verifier + live product link.

4. **50-70s — Selected work #2**  
   ARDA card: LangGraph orchestrator, 577 offline tests, deployed 24/7.

5. **70-85s — About / looking for**  
   Retrieval-grounded LLM work; Montclair + remote/relocation.

6. **85-90s — Contact**  
   Email compose with subject prefilled.

## Pass criteria

- No dead links on the path
- Thesis understood without scrolling past metrics
- At least one production proof and one eval/testing proof seen
- Contact reachable in <=2 clicks from hero path
