Student self-audit toolkit

Use only your own accounts. Do not attempt unauthorized access. Scope expansion awaits DI-18.

1. Policy sweep

  • Find privacy notice, FERPA, student records, and information-security pages.
  • Save URLs, dates, and screenshots.
  • List every vendor named in those pages.

2. Browser audit (own login)

  • Open DevTools → Network on one LMS page.
  • Note third-party domains after load.
  • Export HAR only to a private folder; redact before sharing.

3. Cookie inventory

  • List cookies set on portal hostnames.
  • Flag unknown third-party cookies.
  • Compare against the privacy notice.

4. Records request draft

  • Ask for EdTech contracts and data-sharing agreements.
  • Ask for analytics vendor lists and retention schedules.
  • Track response dates; publish only released material.
