DocMind

Active

Upload a PDF, ask a question, get an answer that names the page it came from. Runs locally on Ollama and ChromaDB with no API key.

Problem
Retrieved PDF text is attacker-controlled context. A RAG demo that skips injection filtering and page-level citations cannot be checked.
Built
Page-level citations carried from PyMuPDF through ChromaDB to the response, prompt-injection filtering on retrieved chunks, HS256 JWT auth, rate-limited upload and ask endpoints, and a confidence score with a low-confidence flag.
Tested
113 tests pass. CI runs ruff, pytest and pip-audit on every push; a Playwright E2E workflow covers login, upload and ask. Retrieval quality is not measured yet, and the README says so.
