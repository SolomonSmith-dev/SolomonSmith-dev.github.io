CourtRules judge assistant

Production

Ask a filing question on a judge's page and get an answer quoted from that judge's own filed orders. Built as a founding engineer at Recursa AI, on a platform covering 1,653 judges.

Problem
Grounding a model in source text does not stop it from inventing a confident quote.
Built
Fetches filed court orders from object storage, extracts text per page, grounds the model in that text, and streams verified answers as NDJSON.
Result
Fails closed: a claim renders only if its quoted sentence appears verbatim in the source. The verifier's tests caught a bypass, an invented quote passing on a plausible source index, before release.
  • TypeScript
  • Next.js
