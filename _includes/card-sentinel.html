Sentinel

Active

A security monitor for my own home network, built so no IP, MAC or payload leaves the house.

Problem
I self-host DNS, media and services on a Debian server and wanted to watch that network with a tool I control, not a cloud one.
Built
A C++17 libpcap sensor and Suricata feed a Python shipper that runs detection rules and an isolation-forest anomaly score, then ships anonymized one-minute rollups to a Cloudflare Worker and D1 behind a public dashboard.
Rigor
Capture memory is bounded and tested by exact pcap replays. ML loading survives an old CPU that crashes numpy. Ingest is idempotent and rejects any batch containing an IP or MAC. The public dashboard shows labeled synthetic data until the home sensor reports.
