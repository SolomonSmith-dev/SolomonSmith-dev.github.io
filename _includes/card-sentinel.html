Sentinel

In production

A security monitor for my own home network, built so no IP, MAC or payload leaves the house.

Problem
I self-host DNS, media and services on a Debian server and wanted to watch that network with a tool I control, not a cloud one.
Built
A C++17 libpcap sensor and Suricata feed a Python shipper that runs detection rules and an isolation-forest anomaly score, then ships anonymized one-minute rollups to a Cloudflare Worker and D1 behind a private, email-authenticated dashboard.
Tested
119 vitest on the Workers runtime, 197 pytest, 4 ctest including exact-count pcap replays. Capture memory is bounded. Ingest is idempotent and rejects any batch containing an IP or MAC.
