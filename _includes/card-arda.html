Deployed

A Claude orchestrator in front of a shell, with numbers on where the routing fails. Multi-agent service on one FastAPI surface, running 24/7 on my own Debian server.

Built
LangGraph orchestrator on native Anthropic tool_use, a Redis-backed shell executor, LlamaIndex RAG, and an MCP server: 7 agents behind 17 HTTP routes and 4 MCP tools.
Tested
577 of 582 tests pass with no API keys or network in 29 seconds (5 skips need a real key). CI runs ruff, mypy, pytest, and the mock evals twice, failing on drift from the committed baseline.
Measured
A labelled eval set with 16 injection cases shows the offline router leaking 12. Demo mode closes the gap structurally: shell refused at the router, in the agent and in the worker, with every route swept against the OpenAPI schema.
