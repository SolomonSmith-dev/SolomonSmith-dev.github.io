ARDA

Deployed

A Claude orchestrator in front of a shell, with numbers on where the routing fails. Multi-agent service on one FastAPI surface, running 24/7 on my own Debian server.

Built
LangGraph orchestrator on native Anthropic tool_use, a Redis-backed shell executor, LlamaIndex RAG, and an MCP server: 7 agents behind 20 HTTP routes and 4 MCP tools.
Tested
The whole test suite runs with no API keys or network, using deterministic mock LLM and embedder doubles. CI runs ruff, mypy, pytest, the mock evals and a README-results check on every PR, failing on drift from the committed baseline.
Measured
A labelled eval set with 16 injection cases shows the offline router leaking 12. Demo mode closes the gap structurally: shell refused at the router, in the agent and in the worker, with every route swept against the OpenAPI schema.
