SOC Triage AI

Shipped v1.0

RAG-grounded security alert triage that refuses out-of-scope alerts instead of guessing.

Problem
A SOC tool that makes up a triage is worse than one that says manual review. The failure path is the product.
Built
Six-stage pipeline: regex observable extraction, sentence-transformer retrieval over an 11-document MITRE ATT&CK corpus, a similarity guardrail at 0.20, Claude generation held to retrieved context, and strict JSON schema validation.
Measured
A 100-case harness (60 standard, 40 adversarial) replayed in CI without an API key. Live run: 76 of 100 passing. Refusal precision 1.0 on 84 labelled alerts. 109 pytest tests.
