Active

A phishing URL classifier I had to break before I could trust it. The dataset leakage I found is documented in the repo.

Built
LightGBM URL classifier exported to ONNX. FastAPI serves it through ONNX Runtime in production, then applies the isotonic calibrator.
Result
Test AUC 0.9943 with a 1.54% false-positive rate on Tranco top-5,000 domains, which were never trained on.
Rigor
Found and fixed inverted labels and distribution leakage in the PhiUSIIL dataset (100% of legitimate URLs were https://www). Leakage tests run in pre-commit and the method is written up in LIMITATIONS.md. 35 test functions, 1 xfail on purpose.
