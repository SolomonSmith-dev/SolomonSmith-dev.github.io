v0.1.0

Claude Code workers in sandboxed git worktrees, every tool call recorded in SQLite, and a draft PR only after an independent reviewer approves the diff.

Problem
An agent's word is a claim, not evidence.
Built
The orchestrator re-runs the reproduction before the fix, runs the tests itself at the reviewed commit, and hands the reviewer the plan, the diff and the test output, never the implementer's transcript. git push and gh never leave the orchestrator's process.
Tested
524 tests, run in CI on Ubuntu and macOS under the real sandbox runtime. 14 of 15 build steps merged, one PR per step. No paid eval has been run yet.
