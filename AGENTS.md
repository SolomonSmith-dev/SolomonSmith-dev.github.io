# AGENTS.md

Personal website built with Jekyll and served by GitHub Pages: hand-written layouts, one SCSS stylesheet, content in Markdown. Light and dark themes.

## Layout

- `_layouts/`, `_includes/`: page templates and components (`default`, `home`, `page`, `project`, `post`).
- `assets/main.scss`: the only stylesheet. Design tokens are CSS variables under `:root`. It does not import Minima, and `_sass/minima/` is unused: do not edit it.
- `_projects/`, `projects.md`: one page per project plus the listing.
- `_posts/`, `blog.md`: blog posts and the index. Do not generate posts unless asked.
- `_data/`: data files. `activity.json` and `activity_log.json` are written by the weekly workflow; never hand-edit them. `featured.json` feeds the home-page numbers.
- `scripts/`, `tests/`: Python helpers and their unit tests.
- `docs/`: plans and specs, excluded from the build.
- `.github/workflows/weekly-activity.yml`: weekly data refresh.

## Commands

Requires Ruby 3.x and Bundler (README, "Local development").

```bash
bundle install
bundle exec jekyll serve --livereload   # preview at http://localhost:4000
bundle exec jekyll build
python3 scripts/check_featured.py       # exit 0 verified, 1 drift or error, 2 bad data file
python3 -m unittest discover -s tests -v
```

## Conventions

- No em dashes in copy, front matter or commit messages. No emojis on the rendered site.
- One accent color. Fonts are Newsreader (display), IBM Plex Sans (body) and IBM Plex Mono (labels and data only). No site JavaScript beyond the two inline theme snippets in `_layouts/default.html`.
- Change colors or type by editing the `:root` variables in `assets/main.scss`.
- `resume.md` and `_includes/skills.html` are generated by `scripts/sync-resume.sh`; do not hand-edit them.
- Every number on the site must be traceable to a source file or a command that reproduces it. Change a featured number only by editing its row in `_data/featured.json` and rerunning `scripts/check_featured.py` until it reports `verified`.
- Project pages stay short (150 to 300 words) and use numbers only from the project's own README.

## Safety

- Never commit secrets or tokens. The weekly workflow reads its token from a repository secret.
- The `CNAME` file sets the custom domain; leave it as is.
- Do not run deploy steps. Pages builds on every push to `main`.

## Done

`bundle exec jekyll build` succeeds, the unit tests pass, and `scripts/check_featured.py` exits 0 (where the source repos it references are available).
